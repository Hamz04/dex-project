How CREATE2 Works

OPCODE

The CREATE2 opcode enables deterministic contract deployment. Unlike CREATE (which depends on nonce), CREATE2 addresses are determined by:

// Solidity
address addr = address(uint160(uint256(
  keccak256(abi.encodePacked(
    bytes1(0xff),
    deployer,
    salt,
    keccak256(bytecode)
  ))
)));

Benefits in Flux Protocol:

  • Pool addresses are predictable before deployment
  • Frontend can compute pair addresses without querying chain
  • Enables gasless address verification
  • Factory pattern with deterministic child contracts
